OOP — Héritage & Polymorphisme

🎭 Polymorphisme par Signature (Surcharge)

public class Passenger
{
    // Surcharge 1 : 2 paramètres
    public bool CheckProfile(string firstName, string lastName)
        => FirstName == firstName && LastName == lastName;

    // Surcharge 2 : 3 paramètres
    public bool CheckProfile(string firstName,
        string lastName, string email)
        => FirstName == firstName && LastName == lastName
           && EmailAddress == email;

    // Surcharge 3 : paramètre optionnel (remplace les 2)
    public bool CheckProfile(string firstName,
        string lastName, string email = null)
    {
        if (email != null)
            return FirstName==firstName && LastName==lastName
                   && EmailAddress==email;
        return FirstName==firstName && LastName==lastName;
    }
}

🎭 Polymorphisme d'Héritage (override)

public class Passenger
{
    public virtual void PassengerType()
        => Console.WriteLine("I am a Passenger");
}

public class Staff : Passenger
{
    public override void PassengerType()
    {
        base.PassengerType(); // appel méthode mère
        Console.WriteLine("and I'm a staff member");
    }
}

public class Traveller : Passenger
{
    public override void PassengerType()
    {
        base.PassengerType();
        Console.WriteLine("and I'm a traveller");
    }
}
virtual + override = comportement déterminé à l'exécution selon le type réel.

Syntaxe Requête (SQL-like)

    .OrderBy(f => f.FlightDate)

// Moyenne des durées > 100

    .Where(f => f.EstimatedDuration > 100)
    .Average(f => f.EstimatedDuration);

.Select(proj)Transformer/projeter.Select(f => f.FlightDate)
.OrderBy/.OrderByDescendingTrier.OrderByDescending(f => f.Date)
.Average()Moyenne.Average(f => f.Duration)
.GroupBy(key)Grouper.GroupBy(f => f.Destination)
.Take(n) / .Skip(n)Limiter.Take(3) → 3 premiers
.OfType<T>()Filtrer par type.OfType<Traveller>()
.Count()Compter.Count()
.FirstOrDefault()Premier ou null.FirstOrDefault()
.ToList()Matérialiser.ToList()
⚠️ Exécution différée : écrire la requête LINQ ne récupère pas les données. Il faut l'exécuter avec .ToList(), foreach, .Count(), etc.

🔗 Méthodes d'Extension

Ajoutent des fonctionnalités à un type existant sans modifier son code. Méthode static dans classe static, premier param this TypeCible.

public static class PassengerExtension
{
    // Extension sur Passenger : met en majuscule prénom + nom
    public static void UpperFullName(this Passenger p)
    {
        p.FirstName = p.FirstName[0].ToString().ToUpper()
                    + p.FirstName.Substring(1);
        p.LastName = p.LastName[0].ToString().ToUpper()
                   + p.LastName.Substring(1);
    }
}

// Extension sur IEnumerable<int> :
public static int CountPairs(this IEnumerable<int> source)
    => source.Count(x => x % 2 == 0);

⚙️ Fluent API — Configurations

PlaneConfiguration

public class PlaneConfiguration
    : IEntityTypeConfiguration<Plane>
{
    public void Configure(
        EntityTypeBuilder<Plane> builder)
    {
        builder.HasKey(p => p.PlaneId);
        builder.ToTable("MyPlanes");
        builder.Property(p => p.Capacity)
               .HasColumnName("PlaneCapacity");
    }
}

public class PassengerConfiguration
    : IEntityTypeConfiguration<Passenger>
{
    public void Configure(
        EntityTypeBuilder<Passenger> builder)
    {
        builder.OwnsOne(p => p.FullName, fn =>
        {
            fn.Property(f => f.FirstName)
              .HasMaxLength(30)
              .HasColumnName("PassFirstName");
            fn.Property(f => f.LastName)
              .IsRequired()
              .HasColumnName("PassLastName");
        });
    }
}

FlightConfiguration (Relations)

public class FlightConfiguration
    : IEntityTypeConfiguration<Flight>
{
    public void Configure(
        EntityTypeBuilder<Flight> builder)
    {
        // One-to-Many : Plane → Flights
        builder.HasOne(f => f.Plane)
               .WithMany(p => p.Flights)
               .HasForeignKey(f => f.PlaneId);

        // Many-to-Many : Flight ↔ Passenger
        builder.HasMany(f => f.Passengers)
               .WithMany(p => p.Flights)
               .UsingEntity<Ticket>(
                   j => j.HasOne(t => t.Passenger)
                          .WithMany(p => p.Tickets)
                          .HasForeignKey(t => t.PassengerId),
                   j => j.HasOne(t => t.Flight)
                          .WithMany(f => f.Tickets)
                          .HasForeignKey(t => t.FlightId)
               );
    }
}

Stratégies d'héritage

🌳 TPH — Table Per Hierarchy (1 table)

Stratégie par défaut dans EF Core. Une seule table avec colonne discriminante.

// Dans OnModelCreating :
modelBuilder.Entity<Passenger>()
    .HasDiscriminator<int>("IsTraveller")
    .HasValue<Passenger>(0)   // 0 = Passenger
    .HasValue<Traveller>(1)  // 1 = Traveller
    .HasValue<Staff>(2);     // 2 = Staff
✅ IsTraveller = 0 → Passenger | 1 → Traveller | 2 → Staff
Avantage : simplicité, performances. Inconvénient : colonnes NULL pour les sous-classes.

🌳 TPT — Table Per Type (N tables)

Une table par classe dans la hiérarchie. Les propriétés héritées restent dans la table mère.

// Via annotations :
[Table("Travellers")]
public class Traveller : Passenger { }

[Table("Staffs")]
public class Staff : Passenger { }

// OU via Fluent API :
modelBuilder.Entity<Traveller>().ToTable("Travellers");
modelBuilder.Entity<Staff>().ToTable("Staffs");
Examen : pour TPT via annotations → [Table] sur les classes filles.
Chargement des données

😴 Lazy Loading

  • Données chargées automatiquement au premier accès
  • Toutes nav properties → virtual
  • Installer EF Core.Proxies
optionsBuilder
  .UseLazyLoadingProxies()
  .UseSqlServer(connStr);

// Propriétés nav = virtual !
public virtual Plane Plane { get;set; }
public virtual IList<Passenger> Passengers
    { get;set; }

🏃 Eager Loading

  • Données chargées dès la requête initiale
  • Utiliser .Include()
var flights = ctx.Flights
    .Include(f => f.Plane)
    .Include(f => f.Passengers)
    .ToList();
Préféré quand on sait à l'avance quelles données sont nécessaires.

🎯 Explicit Loading

  • Chargement manuel avec .Load()
  • Lazy loading désactivé
ctx.Entry(flight)
    .Reference(f => f.Plane)
    .Load();

ctx.Entry(flight)
    .Collection(f => f.Passengers)
    .Load();
Sans Lazy ni Include → NullReferenceException sur nav properties.

// 1. Dates de vol par destination
public List<DateTime> GetFlightDates(string dest)
    => (from f in Flights
        where f.Destination == dest
        select f.FlightDate).ToList();

// 2. Dates et destinations pour un avion
public void ShowFlightDetails(Plane plane)
{
    var req = Flights
        .Where(f => f.Plane == plane)
        .Select(f => new { f.FlightDate, f.Destination });
    foreach(var v in req)
        Console.WriteLine(v.FlightDate + " - " + v.Destination);
}

// 3. Nombre de vols sur 7 jours
public int ProgrammedFlightNumber(DateTime startDate)
    => Flights.Where(f => f.FlightDate > startDate
        && (f.FlightDate - startDate).TotalDays < 7).Count();

// 4. Moyenne durées pour une destination
public double DurationAverage(string dest)
    => Flights.Where(f => f.Destination == dest)
              .Average(f => f.EstimatedDuration);

// 5. Vols ordonnés du plus long au plus court
public IEnumerable<Flight> OrderedDurationFlights()
    => Flights.OrderByDescending(f => f.EstimatedDuration);

// 6. Nationalités des 3 voyageurs les plus âgés
public IEnumerable<string> SeniorTravellers(Flight f)
    => f.Passengers.OfType<Traveller>()
           .OrderBy(p => p.BirthDate)
           .Take(3)
           .Select(p => p.Nationality);

🏗️ GenericRepository (AM.Infrastructure)

        
public class GenericRepository<T>
    : IGenericRepository<T> where T : class
{
    private readonly DbContext _context;
    private readonly DbSet<T> _dbSet;

    public GenericRepository(DbContext context)
    {
        _context = context;
        _dbSet = context.Set<T>();
    }
    public void Add(T entity) => _dbSet.Add(entity);
    public void Delete(T entity) => _dbSet.Remove(entity);
    public void Update(T entity) => _dbSet.Update(entity);
    public IEnumerable<T> GetAll() => _dbSet.AsEnumerable();
    public T GetById(params object[] keys) => _dbSet.Find(keys);
    public IEnumerable<T> GetMany(
        Expression<Func<T, bool>> where)
        => _dbSet.Where(where).AsEnumerable();
    public void Delete(Expression<Func<T,bool>> where)
        => _dbSet.RemoveRange(_dbSet.Where(where));
}

      

    

    

      

        
🔄 IUnitOfWork + UnitOfWork

        
// Interface (AM.ApplicationCore.Interfaces)
public interface IUnitOfWork : IDisposable
{
    int Save();
    IGenericRepository<TEntity>
        Repository<TEntity>() where TEntity : class;
}

// Implémentation (AM.Infrastructure)
public class UnitOfWork : IUnitOfWork
{
    private readonly DbContext _context;
    private readonly Type _repositoryType;
    private bool disposedValue;

    public UnitOfWork(DbContext ctx, Type repoType)
    {
        _context = ctx; _repositoryType = repoType;
    }
    public IGenericRepository<T>
        Repository<T>() where T : class
    => (IGenericRepository<T>)Activator.CreateInstance(
        _repositoryType.MakeGenericType(typeof(T)), _context);

    public int Save() => _context.SaveChanges();

    protected virtual void Dispose(bool disposing)
    {
        if (!disposedValue) {
            if (disposing) _context.Dispose();
            disposedValue = true;
        }
    }
    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }
}

        
⚠️ Le GC ne libère pas DbContext (ressource non managée). Implémenter IDisposable pour la libération déterministe.

      

      

        
🤔 Pourquoi ces patterns ?

        
❓
Problème sans UnitOfWork
Impossible d'utiliser DbContext directement dans AM.ApplicationCore → pas de persistance.

        
✅
Repository
Abstraction de l'accès aux données. Une interface générique, une implémentation réutilisable.

        
✅
UnitOfWork
Centralise les SaveChanges(). Coordonne plusieurs repositories dans une seule transaction.

        
✅
IDisposable
Libère le DbContext proprement quand il n'est plus utilisé.

namespace AM.ApplicationCore.Interfaces
{
    public interface IService<T> where T : class
    {
        void Add(T entity);
        void Update(T entity);
        void Delete(T entity);
        void Delete(Expression<Func<T, bool>> where);
        T GetById(object id);
        T GetById(string id);
        IEnumerable<T> GetAll();
        IEnumerable<T> GetMany(
            Expression<Func<T, bool>> where = null);
        T Get(Expression<Func<T, bool>> where);
        void Commit();
    }
}

      

      

        
Service<T> — Classe générique

        
public class Service<T> : IService<T>
    where T : class
{
    private readonly IGenericRepository<T> _repository;
    private readonly IUnitOfWork _unitOfWork;

    public Service(IUnitOfWork unitOfWork)
    {
        _repository = unitOfWork.Repository<T>();
        _unitOfWork = unitOfWork;
    }
    public virtual void Add(T e) => _repository.Add(e);
    public virtual IEnumerable<T> GetAll()
        => _repository.GetAll();
    public virtual IEnumerable<T> GetMany(
        Expression<Func<T, bool>> filter = null)
        => _repository.GetMany(filter);
    public virtual T Get(Expression<Func<T, bool>> where)
        => _repository.Get(where);
    public void Commit()
    {
        try { _unitOfWork.Save(); }
        catch (Exception) { throw; }
    }
}

public class ServicePlane
    : Service<Plane>, IServicePlane
{
    public ServicePlane(IUnitOfWork uow) : base(uow) { }

    // Vérifier disponibilité places
    public bool AvailablePlane(Flight f, int n)
    {
        int cap = Get(p => p.Flights.Contains(f)).Capacity;
        int nbPass = f.Tickets.Count();
        return cap >= (nbPass + n);
    }

    // Supprimer avions > 10 ans
    public void DeletePlanes()
    {
        foreach(var p in GetMany().Where(p =>
            (DateTime.Now - p.ManufactureDate).TotalDays > 365*10))
        {
            Delete(p); Commit();
        }
    }

    // Vols des n derniers avions
    public IList<IGrouping<int, Flight>>
        GetFlights(int n) =>
        GetAll().OrderByDescending(p => p.PlaneId)
                .Take(n)
                .SelectMany(p => p.Flights)
                .GroupBy(f => f.Plane.PlaneId)
                .ToList();

    // Passagers d'un avion
    public IList<Passenger> GetPassengers(Plane plane)
        => GetById(plane.PlaneId).Flights
               .SelectMany(f => f.Tickets
                   .Select(t => t.Passenger)).ToList();
}

Ce qui tombe toujours à l'examen



  
🔥 ×3 Annotations EF Core

  
Savoir écrire [Key], [Required], [StringLength], [ForeignKey], [EmailAddress], [Range], [Table] et leurs arguments. Apparaît dans TOUS les examens.





  
🔥 ×3 Migrations EF Core

  
Connaître les 3 commandes : Add-Migration NomMig, Update-Database, Remove-Migration. Pour annuler la dernière migration appliquée : Update-Database Mig2 (l'avant-dernière). Projet cible = AM.Infrastructure.





  
🔥 ×3 Fluent API — Relations

  
Savoir configurer HasOne/WithMany/HasForeignKey (1-*), HasMany/WithMany/*-* et HasDiscriminator (TPH). La FlightConfiguration et PlaneConfiguration apparaissent souvent.





  
🔥 ×3 TPH vs TPT — Héritage EF Core

  
TPH = 1 table, colonne discriminante, HasDiscriminator. TPT = 1 table par classe, [Table] sur classes filles ou .ToTable() en Fluent. Le TP demande les deux configurations.





  
🔥 ×3 Repository + UnitOfWork

  
Savoir expliquer pourquoi ces patterns (séparation, persistance, IDisposable). Savoir écrire l'interface IGenericRepository, IUnitOfWork, et leurs implémentations. Le problème sans UnitOfWork = pas de SaveChanges.





  
🔥 ×2 LINQ — Méthodes avancées

  
GroupBy retourne IEnumerable<IGrouping<Key,T>>. OfType<T>() filtre par type. Take(n)/Skip(n) pour paginer. OrderByDescending. Average(). Les exemples du TP (SeniorTravellers, DestinationGroupedFlights) sont fréquents.





  
🔥 ×2 Visibilité par défaut C#

  
Sans modificateur → internal (pas private, pas public). Les membres de classe sans modificateur → private. Question piège très fréquente.





  
🔥 ×2 Action vs Func

  
Action<T> = void (pas de valeur de retour). Func<T, TResult> = retourne TResult (dernier type = type retour). Ex: Func<int> d = CountAll.





  
🔥 ×2 Lazy Loading — Configuration

  
3 conditions : installer EF Core.Proxies + UseLazyLoadingProxies() + toutes les nav properties = virtual. Sans une des 3 conditions → NullReferenceException.





  
🔥 ×2 Architecture N-Couches vs N-Tiers

  
N-Couches = logique (séparation fonctionnelle sur une même machine). N-Tiers = physique (déploiement sur plusieurs machines). Architecture Oignon = logique.

// Stands réservés par exposant sur une période
public IList<Stand> GetStand(
    Exposant expo, DateTime debut, DateTime fin)
    => Stands.Where(s =>
        s.Exposant == expo &&
        s.DateReservation >= debut &&
        s.DateReservation <= fin &&
        s.EstReserve).ToList();

// Gain prévu pour un exposant sur période
public float GetGainPrevu(
    Exposant expo, DateTime debut, DateTime fin)
    => Stands.Where(s =>
        s.Exposant == expo &&
        s.DateReservation >= debut &&
        s.DateReservation <= fin)
    .Sum(s => s.Prix);

// GetSuperExposant : superficie max
public IEnumerable<Exposant> GetSuperExposant(Foire foire)
{
    var groups = Stands
        .Where(s => s.Foire == foire)
        .GroupBy(s => s.ExposantFKey)
        .Select(g => new {
            ExposantId = g.Key,
            TotalSup = g.Sum(s => s.Superficie)
        });
    var max = groups.Max(g => g.TotalSup);
    return groups
        .Where(g => g.TotalSup == max)
        .Select(g => Stands
            .First(s => s.ExposantFKey == g.ExposantId).Exposant);
}
